## قائمة تدقيق إعدادات Word (تُوثَّق قيمها عند التجميد)

هذه إعدادات **تطبيق** تؤثر في العرض ولا تُخزَّن في ملف docx — يجب تثبيتها وتوثيقها:

1. **الأرقام (Numeral):** ‏File ← Options ← Advanced ← Show document content ← Numeral — القيم: ‏Arabic / Hindi / **Context** / System. *(تؤثر مباشرة في شكل الأرقام المعروضة — يجب تثبيتها على قيمة واحدة موثقة).*
2. **اتجاه المستند الافتراضي ولغات التحرير المفعلة** (العربية مفعلة).
3. **إعدادات الكشيدة/التسويغ إن وُجدت في الإصدار** (خيارات التوافق القديمة).
4. **التكبير/التخطيط عند التصدير:** التصدير بـ ExportAsFixedFormat لا يتأثر بالزوم — يوثَّق للاطمئنان.
5. **الخطوط المثبتة:** لقطة كاملة لقائمة خطوط الجهاز تُحفظ مع كل إصدار مرجع (`fonts-snapshot.txt`).
6. **لا إضافات (Add-ins) فعالة** أثناء التوليد.

## إجراء توليد الحقيقة

```powershell
# لكل كتاب في corpus/books:
powershell tools/word-oracle/export_xps.ps1 -Input <book.docx> -Out corpus/ground-truth/<book>.xps
python tools/word-oracle/extract_truth.py corpus/ground-truth/<book>.xps   # ← <book>.truth.json
git add corpus/ground-truth && git commit   # (Git LFS)
```

‏CI لا يشغّل Word أبدًا — يقارن ضد `*.truth.json` المودعة فقط (قيد ترخيص أتمتة Office — ‏ADR-0003).
