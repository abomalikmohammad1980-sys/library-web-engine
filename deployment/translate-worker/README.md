# عامل الترجمة v18 — نسخة المراجعة المصححة

هذا المجلد مستقل عن `deployment/cloudflare`. اسم العامل وربط KV وR2 وDurable Objects وAnalytics والأسرار لم تتغير. لا تنشر هذه النسخة تلقائيًا بمجرد حفظها في المستودع.

## الإصلاحات

- استعادة 16 سطرًا أصابها تكرار فك الترميز، بعكس التحويل والتحقق من مطابقة البايتات الأصلية. يشمل ذلك رسائل الخطأ وعلامات الترقيم وحدود الاقتباس.
- رفض JSON بقيمة `null` أو مصفوفة أو قيمة بسيطة، والتحقق الدقيق من نوع المحتوى وترميز UTF-8.
- حد 64 KiB لجسم الطلب، يُطبّق أثناء قراءة التدفق حتى دون `Content-Length`. لا يتغير الحد الأصلي للنص: 6000 وحدة UTF-16.
- الحفاظ على فواصل الفقرات عند تقسيم النص لذاكرة الترجمة.
- تسجيل محاولات Gemini وGroq وMistral وDeepL وCloudflare AI قبل استدعاء المزوّد، بما فيها المحاولات التي تفشل، وإعادة فحص الحصة قبل محاولة Gemini البديلة.

## الاختبار المحلي

Node.js 22 أو أحدث، دون تثبيت حزم إضافية:

```sh
node --check deployment/translate-worker/src/index.js
node --experimental-vm-modules --test deployment/translate-worker/test/worker.test.mjs
```

الاختبارات تستخدم VM ومحاكاة KV والمزوّدين وDurable Object؛ لا تستعمل مفاتيح أو شبكة أو موارد الإنتاج. تشمل المدخلات الخاطئة والكبيرة، العربية وتقسيم الفقرات، استرجاع الترجمة، حساب المحاولات وتجميع الطلبات المتزامنة المتطابقة. محاكاة Cloudflare لا تثبت وحدها سلوك العمل متعدد المناطق.

## حدود المراجعة قبل التشغيل

- حصص الاستخدام الحالية مبنية على قراءة وكتابة KV، وهي **تقديرية وليست حدًا ماليًا صارمًا**: الطلبات المختلفة المتزامنة قد تقرأ العدّاد نفسه، وKV متسق في النهاية. تجميع الطلبات المتطابقة في Durable Object لا يجعل عدادات المزوّدين ذرية. إن كان المطلوب سقفًا ماليًا قاطعًا، يجب نقل حجز حصص المزوّدين إلى منسّق ذري والتحقق منه قبل النشر.
- لم تُنفّذ ترجمة حية ولم تُختبر المفاتيح أو توافر أسماء النماذج أو استحقاقات الحسابات لدى المزوّدين. بقي `wrangler.toml` مطابقًا للتسليم، ولا تعني تسمية المسار «مجانيًا» ضمان عدم الفوترة لدى كل مزوّد.
- فشل CI العام في المستودع قبل هذه الإصلاحات بسبب غياب ثلاثة ملفات من `alpha-publish/scripts` أثناء بناء التطبيق. ذلك منفصل عن تجميع هذا العامل واختباراته، ولا تُوصف فحوص المشروع العامة بأنها ناجحة.

## تثبيت طريقة الإخراج

حافظت المراجعة على أوامر الترجمة، وترتيب المزوّدين، والنماذج، ومفاتيح ذاكرة الترجمة وإصداراتها، ومسار المقاطع وإعادة استخدامها، وجميع إعدادات الموارد. لم تُفعّل مزوّدًا جديدًا أو مسارًا مدفوعًا. التغيير في عداد DeepL يحجز المحاولة قبل إرسالها، بما فيها المحاولة البديلة والفاشلة.

نجحت 36 حالة اختبار معزولة. تشمل اللغات الـ36 المعلنة عند استرجاع النص المعتمد من الذاكرة، وعناوين كتب وأسماء مؤلفين ونصوص واجهة جديدة مع إعادة استخدام الناتج دون استدعاء إضافي. هذه اختبارات للمسار والحفظ، وليست إثباتًا لجودة الترجمة الحية في كل لغة أو لاستحقاق الحسابات المجانية لدى المزوّدين.
