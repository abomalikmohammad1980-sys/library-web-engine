# اسم عائلة الخط المضمن

## الحالة المؤكدة

اسم `w:font@w:name` هو الاسم الذي تشير إليه `w:rFonts`. لا يجوز الاعتماد فقط على
name table داخل ملف subset، لأنه قد يحمل اسمًا داخليًا اصطناعيًا مختلفًا.

## الدليل

- في «زهر الخمائل» الوجهان font34/font35 معلنان باسم `29LT Bukra Bold`، بينما
  name table بعد فكهما يعيد `___WRD_EMBED_SUB_3030`.
- يظهر النمط نفسه باسم `___WRD_EMBED_SUB_1782` و`___WRD_EMBED_SUB_2627` في كتابين
  آخرين؛ تسجيل هذه الأسماء يمنع `font-family` المعلن من مطابقة الوجه المضمن.
- خصائص section المقيسة مدعومة، و`rtlGutter` لا يغير هندسة corpus لأن gutter=0
  في المقاطع الـ26، لذلك لم يضف تعديل صفحة بلا أثر.

## القاعدة

يحفظ كل وجه مضمن اسم عائلة عقدة `w:font` المالكة، ويسجله FontFace بهذا الاسم.
لا يُستخدم name table إلا fallback لملف لا يملك metadata في fontTable.

## الاختبار

انحدار corpus يثبت أن font34 وfont35 كلاهما يسجلان `29LT Bukra Bold` رغم اسم
subset الداخلي، مع استمرار اختبار عدد الأوجه وأنماطها.
