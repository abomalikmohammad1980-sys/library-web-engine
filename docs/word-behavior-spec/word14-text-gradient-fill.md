# تدرج حشو النص `w14:textFill`

## الحالة المؤكدة

`w14:textFill/w14:gradFill` يلوّن الغليفات نفسها بتدرج، لا خلفية الرن. يحمل
قائمة نقاط `w14:gs` ومواضعها وألوان srgb أو theme وتحويلات shade/tint وغيرها.

## الدليل

- corpus الكتب العشرة يحوي 396 تدرج نص: 370 أساسها الأحمر، و17 accent6،
  و7 accent4، وحالتان بالأسود.
- كان المحلل يتجاهل `w14:textFill` كليًا، فيسقط إلى `w:color` أو اللون الموروث.

## القاعدة

1. يحل النموذج نقاط srgb/theme مع tint/shade/satMod/lumMod/lumOff ويحفظ
   موضع كل نقطة بين 0 و1.
2. تحول زاوية `w14:lin@ang` من أجزاء 60000 من الدرجة إلى CSS مع إزاحة اتجاه
   DrawingML نفسها المستخدمة لتدرجات الأشكال.
3. يخرج DOM linear-gradient مع `background-clip:text` ولون شفاف، لكي يقص
   التدرج داخل الغليفات.
4. تبقى الخاصية موروثة عبر سلسلة rPr، والتدرج المباشر يقدم على النمط.

## الاختبار

اختبار النموذج يثبت تحويل shade والزاوية والنقاط، واختبار DOM يثبت قص التدرج
داخل النص؛ وإحصاء corpus يثبت 396 حالة فعلية.
