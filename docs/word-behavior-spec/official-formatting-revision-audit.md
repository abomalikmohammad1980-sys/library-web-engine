# تدقيق تغيير التنسيق المتعقب — عينة Open XML SDK الرسمية

## المصدر والأمان

- العينة: `trackChange.docx` من مستودع Microsoft Open XML SDK الرسمي، مسار
  اختبارات `wordprocessing/track change`، ومحفوظة تحت `tmp/Word external QA` فقط.
- SHA-256: `95701A8D144DE8B7CFC82198274570C97E5E852F86C414726C78261541F0845D`.
- 11 جزءًا و10,496 بايت، بلا VBA أو OLE أو ActiveX أو embeddings أو تنفيذيات.

## نتيجة Word والنموذج

- Word COM: صفحة واحدة، فقرة واحدة، ومراجعة واحدة من النوع 3 (تغيير تنسيق)
  على كلمة `track` للمؤلف `jazh`، بتاريخ 2008-05-15.
- XML الفعلي لا يحوي `w:ins` أو `w:del`؛ يحوي `w:rPrChange` تاريخيًا تحت
  خصائص الرن الحالية التي تجعل `track` غامقة وحمراء.
- PDF Word يعرض النص النهائي كاملًا والكلمة غامقة حمراء. النموذج أعاد النص
  نفسه، و`bold=true` و`color=FF0000` للكلمة، أي إنه لا يستبدل التنسيق الحالي
  بصورة الخصائص القديمة داخل `w:rPrChange`.
- لا فجوة عرض مثبتة؛ أضيف synthetic regression يحرس أولوية خصائص الرن الحالية.
  سجل المراجعة التأليفي ليس جزءًا من عقد قارئ العرض، لذلك لم تُختلق له واجهة.
