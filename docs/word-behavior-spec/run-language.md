# لغة الرن `w:lang`

## الحالة المؤكدة

يحمل `w:lang` ثلاث قنوات مستقلة: `val` للنص اللاتيني، و`bidi` للنص ثنائي الاتجاه،
و`eastAsia` لنصوص شرق آسيا. يجب دمج كل قناة مستقلًا عبر سلسلة rPr ثم وضع اللغة
المناسبة على عنصر الرن.

## الدليل

- corpus يحوي 12,438 عقدة: 10,478 منها تحمل `bidi` عربيًا (أكثرها ar-EG وar-JO)،
  و1,660 تحمل `val` إنكليزية، والباقي لغات عربية/روسية/صينية وتراكيب متعددة.
- كانت القيم تسقط كليًا، فيفقد المتصفح مدخل اختيار الغليفات والـOpenType والنطق.

## القاعدة

1. تدمج `val` و`bidi` و`eastAsia` كخصائص مستقلة؛ لا يمحو عنصر مباشر جزئي قناة موروثة.
2. الرن RTL يختار `bidi` أولًا، والرن غير RTL يختار `val` ثم `eastAsia`.
3. يوضع الاختيار في سمة HTML `lang` على span نفسه، لا كخاصية CSS.

## الاختبار

اختبار النموذج يثبت وراثة en-US/zh-CN مع تجاوز bidi مباشر ar-SY، واختبار DOM
يثبت اختيار ar-SY للرن RTL وen-US للرن LTR.
