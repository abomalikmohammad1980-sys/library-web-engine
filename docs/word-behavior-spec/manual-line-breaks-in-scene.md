# فواصل الأسطر اليدوية `w:br` في مشهد Word

## الحالة المثبتة

يحوّل نموذج OOXML عنصر `w:br` الافتراضي أو `textWrapping` إلى محرف `LF` داخل
نص الفقرة. كان مشهد الصفحات يقسم نص كل run عند المسافة U+0020 فقط؛ لذلك بقي
`LF` داخل كلمة واحدة ووصل إلى HarfBuzz كغليف، ولم يُغلق السطر في موضع Word.
ظهر الأثر بوضوح في ديوان «هموم وآلام»، الذي يحوي 1111 فاصلًا يدويًا مستخدمًا
في بناء الأبيات الشعرية.

## القاعدة

- `LF` حد سطر إجباري، وليس مسافة ولا جزءًا من نص الكلمة.
- يرتبط الفاصل بآخر كلمة مرئية قبله عبر `BreakItem.forcedBreakAfter`.
- قد يأتي `w:br` في run مستقل؛ عندئذ يرتبط بآخر كلمة في run المرئي السابق.
- السطر المغلق يدويًا لا يُسوّغ، حتى لو كانت الفقرة `w:jc="both"`.
- `NBSP` لا يتغير ويبقى داخل الكلمة، كما كان قبل الإصلاح.
- `w:br type="page"` لا يدخل هذا المسار؛ النموذج يعالجه حد صفحة مستقلًا.

## التحقق

- نموذج اصطناعي يغطي فاصلًا داخل/بين runs وفقرة مسوغة.
- انحدار corpus من «هموم وآلام» يثبت كثافة الفواصل، تعدد أسطر الفقرة، وعدم
  تسرب `LF` إلى نص أي `SceneWord`.
