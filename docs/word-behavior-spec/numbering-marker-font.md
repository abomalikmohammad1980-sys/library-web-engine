# خط علامة القائمة

## الحالة المؤكدة

`w:lvl/w:rPr/w:rFonts` ينسق علامة القائمة نفسها، لا متن الفقرة. ولأن قوالب bullet
كثيرًا ما تخزن محرفًا خاصًا، يجب اختيار شريحة ASCII/HAnsi قبل cs عند رسم العلامة.

## الدليل

- corpus يحوي 917 `rFonts` داخل مستويات الترقيم: 293 Wingdings و209 Symbol و244
  Courier New، إضافة إلى خطوط عربية وأسماء أخرى.
- كان المحلل يحفظ حجم علامة المستوى فقط؛ DOM يرث خط الفقرة، فتتحول محارف Wingdings
  وSymbol إلى غليف خاطئ أو مربع مفقود.
- إعداد `autoHyphenation` غائب في الكتب كلها؛ `doNotHyphenateCaps` الوحيد بلا أثر
  عند غياب الفصل الآلي، فلم يُضف عقد hyphenation مفترض.

## القاعدة

يحفظ المستوى `markerFamily` بأولوية ascii ثم hAnsi ثم cs ثم eastAsia. خط rPr المباشر
في الفقرة يبقى أعلى أولوية، وإلا ينتقل خط المستوى إلى span العلامة وحده.

## الاختبار

اختبار النموذج يثبت أن Wingdings يتقدم على Traditional Arabic، واختبار DOM يثبت
إخراج font-family على العلامة.
