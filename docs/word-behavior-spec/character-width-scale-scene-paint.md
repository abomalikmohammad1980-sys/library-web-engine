# مقياس عرض المحارف `w:w`

## الدليل

يظهر `w:w` في 92 رنًا ضمن corpus. كان النموذج يحفظ النسبة وDOM يخرج
`font-stretch`، لكن scene/Canvas كانا يقيسان ويرسمان بنسبة 100%.

## العقد

- القيمة نسبة مئوية: 50 تعني نصف العرض، و100 بلا تغيير.
- تتضاعف تقدمات الغليفات والمسافات الأفقية بالنسبة نفسها قبل كسر السطر.
- صعود/نزول/ارتفاع السطر لا تتغير؛ المقياس أفقي فقط.
- هندسة Canvas تفصل `sx` عن `sy`، وHTML يخرج `font-stretch` مطابقًا.
- القيمة الغائبة أو غير الموجبة تعامل 100%، حفاظًا على التوافق.

## الاختبارات

- مشهد بنسبة 50% يثبت نصف عرض الكلمة والمسافة مع ثبات الصعود.
- هندسة الرسم تثبت `sx=0.5×` و`sy=1×` وثبات صندوق الكلمة المضغوط.
