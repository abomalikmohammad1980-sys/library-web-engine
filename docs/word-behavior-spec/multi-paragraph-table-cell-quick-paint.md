# الخلية ذات الفقرات المتعددة في مخرج paint السريع

## الدليل

عينة Open XML SDK الرسمية
`tmp/Word external QA/OpenXmlSdk-TableCell2Para/table-cell-2-para.docx` تحتوي
12 خلية. الخلية الأولى في الصف الأول تحمل فقرتين متتاليتين:
`Paragraph inside a table cell` ثم `Para2 inside a table cell`.

يحفظ OOXML الفقرتين كعقدتي `w:p` شقيقتين داخل `w:tc`. ويحفظ model هويتهما
المشتركة عبر `tableId + row + col`. كان quick HTML ينشئ `td` لكل فقرة، فيحوّل
الخلية الواحدة إلى خليتين ويغيّر شبكة الجدول.

## القاعدة

1. مفتاح الخلية الفيزيائية هو `tableId:row:col`، وليس فهرس الفقرة.
2. تنشأ `td` واحدة لكل مفتاح، ثم ترسم فقراتها داخلها بترتيب المصدر.
3. يبقى عداد القوائم مشتركًا بين فقرات الخلية نفسها.
4. لا تدعي هذه الدفعة حل تركيب الجداول المتداخلة في quick HTML؛ ذلك عقد مستقل.

## الانحدار

- model وscene يثبتان فقرتين في الخلية الأولى.
- DOM يثبت 12 خلية وطفلين فقريين داخل أول `td`.
- paint يثبت 12 مجموعة خلايا وأن المجموعة الأولى تحمل الفقرتين بالترتيب.
