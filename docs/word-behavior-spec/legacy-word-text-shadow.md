# ظل النص القديم `w:shadow`

## الحقيقة المقاسة

أنشئ مستند Word محلي بثلاثة أحجام Arial ‏12/24/48pt، وفعّل خاصية Font Shadow
القديمة ثم صدره Microsoft Word إلى PDF. أعاد تحليل الغليفين الأسود والرمادي:

| الحجم | إزاحة X | إزاحة Y |
|---:|---:|---:|
| 12pt | 0.48pt | 0.48pt |
| 24pt | 1.02pt | 1.02pt |
| 48pt | 1.98pt | 1.98pt |

القيمة المقصودة قبل تكميم PDF هي `em / 24` في الاتجاهين. لون النسخة الخلفية
ثابت `#C0C0C0`، بلا blur وبعتامة كاملة. هذه خاصية مستقلة عن `w14:shadow`
الحديث ذي المسافة والزاوية واللون الصريحة.

## العقد

- `w:shadow` يرث عبر `docDefaults`/نمط الفقرة/rPr الفقرة، ويقبل الإبطال المباشر
  بالقيم `0/false/off`.
- بعد حسم حجم الرن، يحول إلى `textShadow` بإزاحة `emTwips/24`.
- إذا وُجد `w14:shadow` المحلول فإنه يتقدم ولا يستبدله الظل القديم.
- الظل طبقة رسم فقط؛ لا يدخل النص أو القياس أو البحث والنسخ.

## corpus

مظللاً بعد دمج الرنات وإقصاء الفارغ/المخفي. اختبار الانحدار يثبت أكثر من 200
رنًا، اللون والإزاحة النسبية، إضافة إلى اختبار synthetic للوراثة والإبطال.
