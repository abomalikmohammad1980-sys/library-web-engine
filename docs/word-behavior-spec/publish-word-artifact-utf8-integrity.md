# سلامة UTF-8 في آثار نشر Word

## العقد

- خدمة WordPageMap تكتب JSON بترميز UTF-8 بلا BOM.
- كل قارئ PowerShell لهذه الخرائط يصرح بـ`-Encoding UTF8`؛ الاعتماد على ترميز
  Windows PowerShell الافتراضي يفسد العربية رغم بقاء الخريطة البنيوية صحيحة.
- manifest يجتاز بوابة قبل استعماله: بصمة مصدر DOCX لم تتغير، الخريطة موجودة،
  عدد صفوفها يساوي `totalPages`، الصفحات الفيزيائية متصلة من 1، وحدود النص في
  manifest تطابق الخريطة حرفيًا.
- ملفات المصدر للقراءة فقط؛ إصلاح manifest أو staging لا يكتب إلى مجلد النشر.

## دليل المجموعة

- 23 عملًا / 28 ملفًا: الأحجام والبصمات كلها مطابقة للـmanifest الشامل.
- 6 مستندات Word: 663 صفحة موثقة إجمالًا، وكل الخرائط اجتازت البوابة.
- قبل الإصلاح كانت حدود خمسة مستندات في manifest تظهر mojibake بينما JSON
  الخرائط الأصلية عربي صحيح. بعد القراءة الصريحة اجتاز Windows PowerShell 5
  والقراءة المستقلة بـNode النصوص الستة.
