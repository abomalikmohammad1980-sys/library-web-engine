# Q8: تنظيف آثار انقطاع إخلاء الحزم

التاريخ: 2026-08-09

## المنجز

إخلاء Q6 ينقل المرشح أولًا إلى مجلد داخلي معزول ثم يحذفه. إذا سقطت العملية بين الخطوتين يبقى trash آمنًا لكنه يشغل مساحة. أضيفت دورة صيانة صريحة:

- لا تفحص إلا أسماء `.quota-trash-<uuid>` المطابقة تمامًا.
- لا ترشح إلا المجلدات الأقدم من حد عمر صريح لا يقل عن دقيقة.
- التخطيط dry-run افتراضي ويحمل وقت الإنشاء والعمر المطلوب وmtime لكل مرشح.
- التنفيذ يحتاج `planId` مطابقًا ويعيد حسابه لمنع العبث.
- التنفيذ يأخذ قفل مدير الحزم المشترك.
- يعيد فحص نوع المسار وmtime والعمر بعد أخذ القفل؛ أي تغيير بعد الموافقة يفشل مغلقًا.
- لا تلمس الدورة الحزم النشطة أو السابقة أو أي مجلد عادي، ولا تتبع الروابط الرمزية.

## الاختبارات

1. trash قديم + trash حديث + حزمة نشطة: يُخطط القديم فقط، ويرفض dry-run والخطة المعدلة، ثم يحذف القديم وحده.
2. تغيير trash بعد اعتماد الخطة: يرفض التنفيذ ويبقي الملفات الجديدة بلا حذف.
