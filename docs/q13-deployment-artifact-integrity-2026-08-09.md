# Q13: بوابة سلامة أثر Pages قبل النشر

التاريخ: 2026-08-09

## العقد

- جرد حتمي مرتب لكل الملفات مع الحجم وSHA-256.
- SHA-256 أعلى للـmanifest الكامل لكشف إضافة/حذف/تغيير أي ملف.
- رفض الروابط الرمزية وأنواع الملفات غير العادية والخروج عن جذر الحزمة.
- حد 50 MiB للملف المنفرد داخل البوابة.
- مسح الملفات النصية بحثًا عن مفاتيح خاصة، أسرار/token طويلة، ومسارات مستخدم ويندوز المطلقة.
- دعم تحقق توقيع Ed25519 من مفتاح عام فقط؛ لا تُنشأ أو تُخزن مفاتيح نشر حقيقية في المستودع.
- إعادة بناء manifest ومقارنته قبل النشر تكشف byte drift بعد الموافقة.

## نتيجة الحزمة المحلية الحالية

فُحص `app/dist` دون نشر أو تعديل:

- عدد الملفات الحالي: **292** (الرقم 289 كان لحزمة سابقة؛ لا يُفرض رقم تاريخي على بناء متغير).
- الحجم: **117,195,824 bytes**.
- بصمة manifest: `1d2fd979136e461a4548a437e15f81925dea2ca9a25ce98de3f77fd3ffc435ea`.
- فحص المحتوى والمسارات: ناجح.

هذه البصمة تخص البناء المحلي الحالي فقط، وليست توقيع نشر أو إثباتًا أن الحزمة دُفعت إلى Pages.
