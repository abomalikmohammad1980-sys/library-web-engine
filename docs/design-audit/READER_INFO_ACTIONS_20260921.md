The accessible indicator reports the returned link count or unavailable status; the full explanation and links are revealed only on request. Editor surfaces retain the expanded edition editor. Source downloads sit beside the format and use only verified original bytes (derived catalog JSON is never renamed BOK). Published admin controls remain in their original permission/identity lifecycle container. Local edit and identity-guarded local deletion are available. Buttons retain accessible labels and tooltips while their visual content is compact icons.
