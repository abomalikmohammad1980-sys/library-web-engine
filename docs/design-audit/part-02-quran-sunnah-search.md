# تدقيق التصميم — مركز القرآن، مركز السنة، والبحث

تاريخ التدقيق: 2026-08-10  
النطاق: قراءة كاملة لملفات التصميم `5- الخزانة - مركز القرآن (مستقل).html` و`6- الخزانة - مركز السنة (مستقل).html` و`7- الخزانة - البحث (مستقل).html`، ومقارنتها قراءةً فقط بالمحرك النشط.  
قاعدة الحسم: التنفيذ الحالي هو الأصل عند التعارض؛ أما التصورات الإضافية أدناه فهي فجوات مطلوبة. لم يُنفذ أي تغيير برمجي ضمن هذه الدفعة.

## خلاصة تنفيذية

- **القرآن:** توجد قاعدة فعلية قوية: حزمة نص كاملة، صفحات مصحف حفص، خط عثماني، بحث لفظي مع خيارات التشكيل والعبارة، فهرس جذور، تفاسير محلية، موارد الغريب والقراءات والتصريف والإعراب، اختيار كلمة، نسخ موثق، وتشغيل صوت مع القارئ والسرعة. أكبر الفجوات هي صفحة الآية الموسوعية الموحدة، المقارنة المتوازية، الآية في التراث، التجويد والروايات الفعلية، التزامن الكلمي والتكرار، والبطاقات القابلة للتصدير.
- **السنة:** توجد عقود بيانات موثقة وعينة ذهبية وبحث متن بسيط وبوابة كتب السنة. لا توجد بعد صفحة حديث موسوعية حقيقية، تخريج متعدد المستويات، شجرة إسناد، بطاقة راوٍ، أو بطاقات مشاركة موثقة؛ وهذه كتلة عمل تعتمد أولًا على corpus موحّد ذي provenance.
- **البحث:** البحث الحالي يدعم العبارة/الاشتقاق/الجذر التقريبي، نطاق الكتب والمؤلفين والتصنيفات والقرون والحقول، ترتيبًا وتجميعًا، إبراز المطابقة، فتح الموضع، virtualization وتحميلًا تدريجيًا. كما توجد نواة `packages/search` سريعة مجزأة بثلاثيات المحارف مع pagination وserialize/restore وعقد Worker. الفجوة الحاسمة هي دمج النواة فعليًا مع حزم كتب الشاملة وواجهة البحث، ثم إضافة البحث الفوري متعدد الكيانات، المرشحات الدلالية، التجميعات الموسعة، وحالات الجودة.

## ترتيب دفعات التنفيذ المقترح

1. **الأساس الحرج (P0):** مولد حزم/شاردات كتب الشاملة + Worker فعلي + بحث متعدد الشاردات مع pagination وإلغاء الطلب وSLO؛ ثم توصيل صفحة البحث الحالية به دون تغيير سلوكها المستقر.
2. **توحيد الكيانات (P0):** عقود نتائج `book/author/text/ayah/hadith` وهوية موضع موحدة؛ البحث الفوري بعد ذلك يصبح طبقة عرض فوق نفس الخدمة.
3. **صفحتا الآية والحديث (P0):** صفحة الآية تجمع الموارد الموجودة أولًا؛ صفحة الحديث تبدأ بعد corpus موثق، ولا تُبنى على بيانات العرض التجريبية.
4. **الفهارس العكسية (P0/P1):** الآية في التراث والحديث في التراث، مع عينات precision/recall ودرجات ثقة ظاهرة.
5. **التجارب المتخصصة (P1):** مقارنة التفاسير، word-by-word، التجويد، audio timing/repeat، تخريج المستويات، شجرة الإسناد، بطاقة الراوي، وتجميع/مرشحات البحث الدلالية.
6. **المشاركة والاستكمالات (P2):** بطاقات الآية والحديث، علاقات الكتاب والمؤلف، والشجرة العلمية.

## ضوابط قبول مشتركة

- كل معلومة قرآنية أو حديثية مشتقة تعرض مصدرها وترخيصها/نسبتها، ولا تتحول بيانات العرض التجريبية إلى حقيقة إنتاجية.
- Lucene الرسمي ليس runtime للمتصفح؛ إن استُخدم فمرجع تحقق أو مصدر تحويل وقت البناء فقط.
- كل route يعمل مباشرة بعد reload، وكل حالة loading/error/empty قابلة للاختبار، مع دعم RTL والجوال ولوحة المفاتيح وreduced motion.
- معيار البحث الطرفي: ظهور أول النتائج في أقل من ثانية على corpus ممثل، وإتاحة 10,000 نتيجة عبر pagination وعرض افتراضي دون إنشاء 10,000 عقدة DOM أو إعادة مصفوفة كاملة دفعة واحدة.
- تظل جميع artifacts والفهارس والبيانات تحت جذر المشروع وبمسارات محمولة مشتقة منه.
