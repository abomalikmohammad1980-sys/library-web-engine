# تدقيق البحث والسمات وتنزيل PDF — 2026-08-10

## النتائج

- بحث المؤلفين كان قد أصبح بالفعل substring عربيًا متصلًا بعد تطبيع التشكيل
  والتطويل والألفات والياء والتاء المربوطة؛ ثُبتت حالتا «دع» و«دعا» ← «دعامة».
  صححت رسالة الفراغ كي لا تزعم مطابقة «كل الكلمات» أو تطلب ترتيب الاسم.
- السمات الأربع (`original/light/dark/sepia`) محفوظة وتطبق فورًا على root،
  وتملك ألوانًا متباينة فعلية. قائمة الهاتف fixed بعرض الشاشة وشبكة 2×2، وزر
  الإعدادات ترس ذو aria-label وtitle صريحين.
- أصول PDF لا تعرض تنزيلين: بطاقة المكتبة وصفحة البطاقة وشريط القارئ وبطاقة
  المعلومات تعرض إجراء واحدًا موحدًا باسم «تحميل PDF». يبقى الفرق بين Word
  الأصلي وPDF المولد ظاهرًا فقط لكتب Word.

## الإثبات

- الاختبارات المركزة **20/20** في 5 ملفات: التطبيع/substring، حفظ وتطبيق كل
  سمة، mobile theme menu، وضوح الإعدادات، وعقد PDF الواحد.
- بناء التطبيق الكامل أخضر: TypeScript + Vite، **442 وحدة**.
