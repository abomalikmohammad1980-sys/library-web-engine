# ADR-0002: نموذج التشغيل المزدوج — تخطيط مسبق افتراضيًا، ومتصفح عند الطلب

**الحالة:** معتمد · 2026-07-12

## السياق

صفحات Word ثابتة الأبعاد (الزوم تحجيم لا إعادة تخطيط) والمكتبة للقراءة فقط ⇐ نتيجة التخطيط لكل كتاب **حتمية تُحسب مرة واحدة**. وتشغيل المحرك على كل جهاز مستخدم يحمّل أضعف الأجهزة كلفة حساب متكررة لنتيجة واحدة، ويجعل حتمية العرض رهينة بيئة كل جهاز.

## القرار

المحرك **مكتبة TypeScript نقية** (بلا DOM/Node داخلها) تعمل في وضعين:

- **الوضع أ (الافتراضي):** وقت تحضير الكتاب على الخادم — يُشحن للمستخدم «حزمة كتاب»: شجرة مشهد مضغوطة + خرائط تفاعل + فهارس بحث. العميل راسم خفيف.
- **الوضع ب (عند الطلب):** داخل Web Worker — للميزات التي تعيد التخطيط (تبديل خط القراءة؛ مستقبلًا docx عشوائي). يُحمَّل كسولًا.

كلا الوضعين نفس الكود، ويُختبران بنفس المُحكِّم.

## الثمن المقبول

انضباط «النقاء البيئي» في كل حزم المحرك (ممنوع لمس DOM/Node)، وصيانة صيغة تسلسل لحزمة الكتاب.
